# 演示数据约定

种子数据由 `scripts/generate-seed.ts` 生成，运行 `npm run seed`。不要手改 `src/data/seed/*.json`，下次生成会被覆盖。

## 分布要求
- 12 个档口，约 100 道菜，约 400 条评论。只有“北京味道”来自用户，其余都是虚构的。
- 档口分数要覆盖 0 到约 4.8，让热力差异一眼可见；至少一个档口没有评论（白色）。
- 有评论的菜品数要覆盖榜单的三种情况：≥ 10、6–9、≤ 5。
- 每道菜都必须有 `spicy`。
- 必须有 14 天内上架的菜，否则上新栏会变空。

## 时间
种子数据只存 `listedDaysAgo` 和 `createdDaysAgo`，页面打开时才换算成日期。不要写入绝对日期，因为链接要长期可用。

## 随机
生成脚本使用固定种子，同样的代码产生同样的数据，这样 diff 才能看懂。

## 本地存储
键名带版本号（`chishenme:reviews:v1`），格式不兼容时升版本号。读写都要容错：无痕模式等情况下退回内存存储，页面仍要可用。
