# 模拟后端约定

GitHub Pages 只能托管静态文件，所以“后端”运行在浏览器里。`src/api/client.ts` 定义接口，`src/api/mockServer.ts` 实现。接口都是异步的，将来可以直接换成真实后端。

## 分层
- `src/domain/`：纯函数，不访问存储，不读当前时间。随机数和时间都从参数传入，这样才能测试。
- `src/api/`：把种子数据和本地评论合并，再调用 domain。

## 规则（来自 docs/SPEC.md §4）
- 一条评论 1–5 星。没有评论时评分为 0，显示“暂无评分”。
- 档口评分包括评价菜品和评价档口整体的评论。
- 排序用贝叶斯加权（m = 5），显示用真实平均分。
- 榜单切分：N ≥ 10 取 5/5；6–9 取 3/3；N ≤ 5 取前 ⌈N/2⌉ 和剩下的部分，同一道菜不能同时上两榜。
- 只有本机写入的评论可以删除。

## 测试
改规则时同步更新 `src/domain/*.test.ts`，运行 `npm test`。边界值（N = 0、1、2、5、6、9、10）要覆盖到。
